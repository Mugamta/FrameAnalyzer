# 프레임 분석기 (Frame Analyzer)

영상을 **프레임 단위로** 넘겨보면서, **이전 프레임과 크게 달라지는 지점**을 자동으로 찾아주는 도구입니다.

- **장면 전환**: 화면이 다른 장면으로 바뀌는 지점
- **숨은 컷**: 1~3프레임만 잠깐 끼워 넣었다가 원래 장면으로 돌아오는 컷 (서브리미널 컷, 깜빡이는 한 장면 등)

인스타그램 · 유튜브(숏츠) · 트위터(X) · 틱톡 등의 **링크**를 붙여넣거나, 영상 **파일을 드래그앤드롭**하면 됩니다.

## 실행

1. [Python 3.10 이상](https://www.python.org)을 설치합니다.
2. `start.bat`을 더블클릭합니다.
   - 처음 실행할 때 `.venv` 폴더에 필요한 패키지(yt-dlp, ffmpeg, numpy)를 자동으로 설치합니다.
   - 브라우저에서 `http://127.0.0.1:8770` 이 열립니다.

> 링크로 된 영상은 브라우저만으로는 받을 수 없어서, 이 컴퓨터에서 작은 서버(`server.py`)를 띄워 처리합니다.
> 드래그앤드롭한 파일도 이 로컬 서버로만 전달되고, **외부 어디에도 업로드되지 않습니다.**

## 사용법

1. 위쪽 입력칸에 링크를 붙여넣고 `Enter`를 누릅니다. 아무 곳에서나 `Ctrl+V`를 눌러도 됩니다.
   파일은 화면에 드래그앤드롭하거나 **파일 열기**로 엽니다.
2. 다운로드와 분석이 끝나면 오른쪽에 **감지된 지점** 목록이 나옵니다.
   - 장면 전환: `이전 프레임 → 바뀐 프레임`
   - 숨은 컷: `직전 프레임 → 끼워 넣은 프레임 → 돌아온 프레임`
3. 목록을 클릭하거나 `N`/`B`로 지점 사이를 이동하고, `←`/`→`로 한 프레임씩 확인합니다.

### 화면 구성

| 영역 | 설명 |
|---|---|
| 필름스트립 | 현재 프레임 앞뒤 3프레임씩. 클릭하면 이동 |
| 변화 그래프 | 막대 하나가 프레임 하나. 높을수록 직전 프레임과 많이 다름. 주황 = 장면 전환, 분홍 = 숨은 컷. 휠로 확대/축소, 드래그로 이동, 클릭으로 해당 프레임 이동 |
| 전체 그래프 | 영상 전체. 클릭/드래그로 이동 |
| 민감도 | 높을수록 작은 변화도 잡습니다. 값을 바꾸면 바로 다시 계산됩니다 |

### 단축키

| 키 | 동작 |
|---|---|
| `Space` | 재생 / 정지 |
| `←` / `→` (또는 `,` / `.`) | 1프레임 뒤로 / 앞으로 |
| `Shift` + `←` / `→` | 10프레임 |
| `B` / `N` | 이전 / 다음 감지 지점 |
| `Home` / `End` | 처음 / 끝 |
| `S` | 현재 프레임을 PNG로 저장 |
| `M` | 음소거 |
| `H` | 전체화면 모드 (하단·목록 숨김) |
| 입력칸에서 `Shift` + `Enter` | 캐시를 무시하고 다시 다운로드·분석 |

## 동작 원리

1. **yt-dlp**로 영상을 받습니다. 브라우저에서 재생할 수 있도록 H.264(mp4)를 우선 고릅니다.
   브라우저가 재생하지 못하는 코덱(HEVC 등)으로 된 파일은 H.264로 변환합니다.
2. **ffmpeg**로 **모든 프레임**을 빠짐없이 디코딩하고(프레임을 건너뛰지 않음) 64×64로 줄여서 비교합니다.
   - 픽셀 차이: 직전 프레임과 평균적으로 얼마나 다른지
   - 색 분포(히스토그램) 차이: 카메라 움직임에는 덜 민감하고, 장면이 바뀌면 크게 변함
   - 건너뛴 비교: `i-1`번 프레임과 `i+1`·`i+2`·`i+3`번 프레임 비교
3. 브라우저에서 위 값을 바탕으로 지점을 판정합니다.
   - 변화 점수가 기준선 이상이면서 **주변 프레임들의 평균보다 훨씬 클 때**만 지점으로 봅니다. 그래서 계속 움직이는 영상에서 오탐이 줄어듭니다.
   - 크게 바뀐 직후 1~3프레임 안에 **원래 장면으로 돌아오면**(건너뛴 비교 값이 작으면) 숨은 컷으로 분류합니다.

결과는 `cache/` 폴더에 저장되어, 같은 링크나 같은 파일을 다시 열면 바로 불러옵니다. 공간을 비우려면 `cache/` 폴더를 지우면 됩니다.

## 문제 해결

- **링크가 안 열릴 때**: 사이트가 바뀌면 yt-dlp도 업데이트가 필요합니다. `update.bat`을 실행하세요.
- **쿠키 설정 (로그인이 필요한 인스타그램 게시물 등)**
  브라우저 확장 프로그램(예: "Get cookies.txt LOCALLY")으로 해당 사이트의 쿠키를 Netscape 형식으로 내보내서,
  이 폴더에 `cookies.txt`로 저장하면 됩니다. 이 파일에는 로그인 정보가 들어 있으니 다른 사람과 공유하지 마세요(`.gitignore`에 포함되어 있습니다).
- **포트 변경**: 환경변수 `FRAME_ANALYZER_PORT`를 설정합니다(기본값 8770).
- 페이드처럼 **천천히** 바뀌는 전환은 프레임마다의 변화가 작아서 잡히지 않을 수 있습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `server.py` | 로컬 서버: 다운로드, 변환, 프레임 분석, 영상 전송 |
| `index.html` | 화면 (플레이어, 그래프, 감지 목록) |
| `start.bat` / `update.bat` | 실행 / 패키지 업데이트 |
| `requirements.txt` | Python 패키지 목록 |
