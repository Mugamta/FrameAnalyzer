# 프레임 분석기 (Frame Analyzer)

영상을 **프레임 단위로** 넘겨보면서, **이전 프레임과 크게 달라지는 지점**을 자동으로 찾아주는 브라우저용 도구입니다.

- **장면 전환**: 화면이 다른 장면으로 바뀌는 지점
- **숨은 컷**: 1~3프레임만 잠깐 끼워 넣었다가 원래 장면으로 돌아오는 컷 (서브리미널 컷, 깜빡이는 한 장면 등)

설치나 서버가 필요 없습니다. `index.html` 파일 하나로 동작합니다. 파일은 브라우저 안에서만 처리되므로 **어디에도 업로드되지 않습니다.**

> Chrome 또는 Edge 최신 버전을 권장합니다.

## 사용법

1. 영상 파일을 화면에 **드래그앤드롭**하거나 **파일 열기**를 누릅니다.
2. 분석이 끝나면 오른쪽에 **감지된 지점** 목록이 나옵니다.
   - 장면 전환: `이전 프레임 → 바뀐 프레임`
   - 숨은 컷: `직전 프레임 → 끼워 넣은 프레임 → 돌아온 프레임`
3. 목록을 클릭하거나 `N`/`B`로 지점 사이를 이동하고, `←`/`→`로 한 프레임씩 확인합니다.

### 화면 구성

| 영역 | 설명 |
|---|---|
| 필름스트립 | 현재 프레임 앞뒤 3프레임씩. 클릭하면 이동 |
| 변화 그래프 | 막대 하나가 프레임 하나. 높을수록 직전 프레임과 많이 다름. 주황 = 장면 전환, 분홍 = 숨은 컷. 휠로 확대/축소, 드래그로 이동, 클릭으로 해당 프레임 이동 |
| 전체 그래프 | 영상 전체. 클릭/드래그로 이동 |
| 민감도 | 높을수록 작은 변화도 잡습니다. 값을 바꾸면 바로 다시 계산됩니다 |

### 단축키

| 키 | 동작 |
|---|---|
| `Space` | 재생 / 정지 |
| `←` / `→` (또는 `,` / `.`) | 1프레임 뒤로 / 앞으로 |
| `Shift` + `←` / `→` | 10프레임 |
| `B` / `N` | 이전 / 다음 감지 지점 |
| `Home` / `End` | 처음 / 끝 |
| `S` | 현재 프레임을 PNG로 저장 |
| `M` | 음소거 |
| `H` | 전체화면 모드 (하단·목록 숨김) |

## 지원 형식

| 형식 | 분석 방식 | 속도 |
|---|---|---|
| **mp4 / mov / m4v** (H.264, HEVC, AV1, VP9) | 모든 프레임을 직접 디코딩 ([WebCodecs](https://developer.mozilla.org/docs/Web/API/WebCodecs_API)) | 빠름 (1분 영상 기준 수 초) |
| 그 외 (webm, mkv 등) | 영상을 실제로 재생하면서 화면에 나온 프레임을 분석 | 영상 길이만큼 걸림 |

재생 방식에서 컴퓨터가 느려 프레임이 빠졌다면 상단에 경고가 표시됩니다. 이 경우 mp4로 변환하면 정확하게 분석할 수 있습니다.

인스타그램·유튜브·트위터 영상은 먼저 파일로 받은 뒤 넣어주세요. 브라우저만으로는 다른 사이트의 영상을 받을 수 없습니다.

## 동작 원리

1. 모든 프레임을 빠짐없이 디코딩하고 64×64로 줄여서 비교합니다.
   - 픽셀 차이: 직전 프레임과 평균적으로 얼마나 다른지
   - 색 분포(히스토그램) 차이: 카메라 움직임에는 덜 민감하고, 장면이 바뀌면 크게 변함
   - 건너뛴 비교: `i-1`번 프레임과 `i+1`·`i+2`·`i+3`번 프레임 비교
2. 변화 점수가 기준선 이상이면서 **주변 프레임들보다 훨씬 클 때**만 지점으로 봅니다. 그래서 계속 움직이는 영상에서 오탐이 줄어듭니다.
3. 크게 바뀐 직후 1~3프레임 안에 **원래 장면으로 돌아오면**(건너뛴 비교 값이 작으면) 숨은 컷으로 분류합니다.

페이드처럼 **천천히** 바뀌는 전환은 프레임마다의 변화가 작아서 잡히지 않을 수 있습니다.
